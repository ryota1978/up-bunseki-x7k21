# ユナイテッドファーマシー 配布物管理アプリ

薬局チェーン「ユナイテッドファーマシー」（6店舗・スタッフ29名）向けの、店舗配布物の進捗管理アプリです。
開発依頼書（第2版）に基づき、独立したWebアプリとして作られています。

## 使っている技術

- [Next.js](https://nextjs.org/)（App Router / TypeScript）
- [Supabase](https://supabase.com/)（データベース・複数端末のリアルタイム同期）
- [Vercel](https://vercel.com/)（公開先。URLが変わらない）
- [Tailwind CSS](https://tailwindcss.com/)

## セットアップ

はじめての方は **[SETUP.md](./SETUP.md)** を順番に進めてください
（Supabase / Vercel のアカウント作成から、環境変数の設定、公開までを1つずつ説明しています）。

開発者向けの最短手順：

```bash
npm install
cp .env.example .env.local   # 値を入力する
npm run dev
```

`supabase/schema.sql` をSupabaseの SQL Editor で実行すると、テーブルと初期データ（29組）が作成されます。

## 主な機能

- 案件の追加・修正・「済」管理（通常方式／店舗別チェック方式）
- 案件への添付ファイル（写真・PDFなど、1ファイル10MBまで）
- 会議への転載リスト・医療事務ミーティングへの転載リスト（それぞれ独立してチェック可能）
- 音声入力（音声認識＋AIによる自動入力補助、確認画面を必ず経由）
- 印刷用レイアウト（案件一覧・転載リスト・メンバー一覧）
- 「加藤」「助田」の名前選択（端末に記憶。誰が更新したかの記録用で、アクセス制限ではありません）
- 控え（データのJSONエクスポート／インポート）
- PWA対応（iPhoneのホーム画面に追加できます）

## 今回のトラブルを踏まえた設計上の対応

前回のプロトタイプ（Claudeのアーティファクト機能上で動作）で起きた問題への対応です。詳しくは開発依頼書 第1章を参照してください。

- **URLが変わる問題** → Vercelにデプロイ後は同じURLのまま更新されます
- **埋め込みによる不具合（マイク・ホーム画面追加）** → 独立した通常のWebページとして動作します
- **保存の成功/失敗が分からない問題** → 保存操作ごとに成功/失敗を表示し、失敗時は自動リトライします（`lib/retry.ts`）
- **LINE WORKS内蔵ブラウザでの不具合** → 実機確認が必要です（SETUP.md参照）。崩れる場合は外部ブラウザで開くよう案内してください
